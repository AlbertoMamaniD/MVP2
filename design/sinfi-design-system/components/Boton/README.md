Botón de ancho completo para la acción de cada pantalla.

- **Principal:** `brand` con texto `on-brand`. Uno por pantalla.
- **Secundario:** `surface` con borde `brand`. Para volver o ver otras opciones.
- **Deshabilitado:** `line` con texto `muted`. Se usa hasta que el carnet esté completo.

Alto mínimo de 52px y texto de 17px. El texto es un verbo en tuteo: "Reservar mi ficha", "Ver otros días". El anillo de foco es visible, de 3px en `brand`. Quien lo usa aporta el texto y el manejador de clic.
